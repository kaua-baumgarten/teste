# DreamTeam

DreamTeam é uma aplicação web desenvolvida com Python e Django que permite montar um time de futebol personalizado utilizando jogadores reais. O projeto foi criado com o objetivo de praticar desenvolvimento web, consumo de APIs e organização de projetos utilizando Django.

## Funcionalidades

* Seleção de jogadores por posição.
* Pesquisa de jogadores.
* Exibição da foto do jogador.
* Exibição da nacionalidade.
* Exibição do clube atual.
* Cálculo da média das estatísticas do jogador.
* Salvamento do time em arquivo JSON.
* Interface inspirada no Transfermarkt.

## Instalação

Clone o repositório:

```bash
git clone https://github.com/Augusto08080/DreamTeam.git
```

Acesse a pasta do projeto:

```bash
cd DreamTeam
```

Crie um ambiente virtual:

```bash
python -m venv venv
```

Ative o ambiente virtual.

No Windows:

```bash
venv\Scripts\activate
```

Instale as dependências:

```bash
pip install -r requirements.txt
```

Execute o servidor:

```bash
python manage.py runserver
```

A aplicação estará disponível em:

```text
http://127.0.0.1:8000/
```

## Objetivo

O objetivo do projeto é oferecer uma aplicação simples para criação de um time personalizado de futebol, permitindo ao usuário selecionar jogadores por posição e visualizar informações relevantes sobre cada atleta. O projeto também serve como estudo de desenvolvimento web com Django e integração de dados externos.
